About the job

About Us

EduTrend is a remote-first edtech startup building a behavioral tracking and analytics platform for students with special needs. With development underway and a beta launch planned for Fall 2025, we’re seeking frontend development interns who are ready to write clean, scalable TypeScript code and ship features that matter.




What We’re Building

EduTrend enables schools and specialists to collect, track, and visualize behavioral data for early intervention and support planning. Frontend interns will focus on delivering smooth, reliable, classroom-ready web and mobile experiences.




Intern Responsibilities

Build mobile and web interfaces using TypeScript + React Native + Expo + React Native Web
Implement reusable, accessible UI components in line with our design system
Integrate with backend GraphQL APIs (Apollo Client)
Optimize performance for iOS, Android, and desktop platforms
Collaborate with UX/UI designers to deliver pixel-perfect implementations
Contribute to testing, debugging, and CI/CD pipelines for frontend features




Required Skills

Proficiency in TypeScript and React
Experience with React Native or cross-platform development
Understanding of component-based architecture and state management
Familiarity with Git and collaborative workflows
Clear communication and ability to work async in a remote team




Bonus Skills

Expo or React Native Web experience
Apollo Client or GraphQL query experience
Knowledge of accessibility standards and best practices
Experience with automated testing of React components




What You’ll Get

Experience writing TypeScript in a production-ready codebase
A key role in building a product preparing for beta with real classrooms
Direct collaboration with designers and backend developers in a full-stack environment
Exposure to startup operations and mentorship on the business side of building a company (funding, strategy, growth.
A portfolio-ready contribution to a mission-driven product




Join Us

If you’re a front-end developer or development-focused student who cares deeply about building accessible, performant, and user-friendly web applications, we want to hear from you! Due to being a start-up with a limited budget, this internship would be unpaid. In return, you’ll work on a real product, with real users, writing production-level front-end code and contributing directly to features that are actively used in classrooms while creating meaningful portfolio work that reflects real-world industry practice and helps improve outcomes for students with special needs.

EduTrend is a real-time behavior tracking and analytics platform purpose-built for special education classrooms. In schools supporting students with autism, Down syndrome, cerebral palsy, and other complex needs, educators rely on behavior data to guide interventions. But too often, this data is collected on paper, delayed, or reviewed only after problems escalate.

EduTrend replaces outdated systems with a secure digital platform that empowers educators to log, track, and analyze behavior events as they happen. Using current behavior tracking methodology, staff can enter time-stamped entries with just a few taps—making patterns visible across time, classrooms, and students. Designed with role-based access, paraprofessionals log data, teachers review it for their class, and behaviorists analyze it across the school. No guesswork. No delays. Just better insight, faster.

Crucially, EduTrend does not replace professional judgment. After personally speaking with many special educators and behaviorists, we built tools that match how they already work—offering clarity, not automation. For our educators, that means cleaner data and better decision-making. For students, it means earlier, more effective support.
